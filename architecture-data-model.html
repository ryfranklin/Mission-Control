▲ Mission Control — Data Model (Postgres)

The transactional system-of-record: the operator-facing runs ledger, its durable event log and milestone outbox, and the Flight Plan tables (header, transcript, requirements, and the CONSTRUCTION work-list).

Click a table to inspect it. Companion to architecture.html · architecture-uml.html · architecture-sequence.html.

Notation: crow's-foot one —< many. PK primary key · FK foreign key · UQ unique · IX index · JSONB document column. Renders standalone over file:// — no network, no build.

Select a table to see its purpose, full column list (with PK/FK/UQ/IX markers), and its foreign-key relationships. Hover a table to highlight its edges.

Where's the telemetry table? There isn't one. Postgres is the transactional system-of-record; the per-step telemetry lives OUTSIDE Postgres as a JSONL "bronze" spine queried in place by DuckDB (zero ETL) — different tools, different jobs.
