A run row is authoritative and idempotent: started_at / ended_at are stamped exactly once (COALESCE-guarded), so a replay after a crash can re-run a node without moving a terminal state. Renders standalone over file:// — no network, no build.

Durability & recovery model

Recovery is at node boundaries — a crash re-runs the whole node, so every node (dispatch, run_worker, gate, apply_burn, teardown) is idempotent.

awaiting_gate is a durable interrupt(): the graph halts before apply_burn, persists to the checkpointer, and resumes after a restart without re-paying for completed steps.

Terminal states stamp ended_at exactly once (COALESCE-guarded), so a replay can't move a run that already landed.
